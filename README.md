# ALMAS GAME — тіркелу және кіру (GitHub)

## Админ ID: 1
ID **1** тек әкімшіге арналған және ойыншы ретінде қолданылмайды. Тек GitHub `jjjjjjjjjjjjjjae-hub` иесі репозиторийді өзгерте алады. Әкімшіге кіру үшін ID 1 + GitHub fine-grained PAT қажет (репозиторий `my-game-server`, **Contents: Read and write**). Құпия токенді ешқашан кодқа жазбаңыз немесе ойыншыларға жібермеңіз.

## Ойыншылар
`accounts.json` — ресми ашық тізілім: ID ≥ 2, аты, мәртебесі, құпия код SHA-256 хэші, кіру мерзімі. Кодтың өзі GitHub-қа жазылмайды. Админ APK-дағы **«Админ ID 1»** бөлімінен жаңа ойыншы жасап, жеке құпия кодын бір рет көреді. Ойыншыға ID және сол код бөлек беріледі.

APK тексеретін ресми URL:
https://raw.githubusercontent.com/jjjjjjjjjjjjjae-hub/my-game-server/main/accounts.json

## GitHub Pages
Қаласаңыз Settings → Pages → Deploy from a branch → main / (root) арқылы статикалық тізілімді `github.io` сайтында да көрсетуге болады. Жай GitHub Pages сервер емес және ойыншылардың онлайн байланысын, сенімді серверлік ойын уақытын есептеуді қамтамасыз етпейді.

## Маңызды шектеу
Бұл **тест нұсқасындағы жергілікті кіру бақылауы**. Өзгертілген APK қорғанысты айналып өтуі мүмкін. GitHub-тағы деректерді өзгертуді репозиторий рұқсаттары қорғайды; барлық ойыншыларды сервер деңгейінде бұғаттау және нағыз ойын уақыты есептегіші үшін backend қажет. 30 минут мәні *аккаунт жасалғаннан кейінгі 30 минуттық қолжетімділік мерзімі*, жинақталған ойын уақыты емес. Интернет болмаса бағдарлама кіруге рұқсат бермейді. Токенді қорғау үшін GitHub 2FA қосыңыз.
